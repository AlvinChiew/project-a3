# AI Review Reply — User Guide

Turn a rude or messy review into a polished reply you can post yourself on Google, Facebook, or Xiaohongshu.

## Before you start

1. Get a free activation code at [project-a3.alvinchiew.com](https://project-a3.alvinchiew.com/#signup).
2. Add your **OpenAI API key** in **Settings** and click **Test connection**.

## Install

1. Download **EP07 AI Review Reply** from [Project A3 on GitHub](https://github.com/AlvinChiew/project-a3).
2. Run the installer and open **AI Review Reply**.

## Activate (one time)

1. On the welcome screen, read and tick the **disclaimer**.
2. Enter your business email and `A3-XXXX-XXXX` code, then click **Activate**.

## First setup (recommended)

1. Open **Settings**.
2. Fill **Product info** (what you sell, refunds/hours, audience).
3. Add a few **Review → response examples** from replies you like — turn **Include** on for the best ones.
4. Optionally set **Brand voice** (You must / Never / Style).

You can still generate without product info, but drafts will be more generic.

## Write a reply

1. Click **New reply** on History.
2. Choose the platform (Google / Facebook / Xiaohongshu).
3. Paste the customer review. Optionally add stars and a short note.
4. Click **Generate drafts**.
5. Pick a variant (grateful / apologetic / firm), edit the text, then **Copy**.
6. Paste the reply on the platform yourself — this app does not post for you.

## History and CSV

- Open past jobs from **History**.
- **Copy CSV** exports review + chosen reply (with an A3 footer) to the clipboard.

## Tips

- AI drafts may be inaccurate — always review before posting.
- Add product info and included examples for replies that match your business.
- The app never invents offers or policies not in your product info.

## Common issues

| Problem | What to try |
| ------- | ----------- |
| Generate fails / key error | Re-save your OpenAI key in Settings and Test connection |
| Weak drafts | Add product info + a few included examples |
| App asks to activate again | Use the same business email and a valid `A3-XXXX-XXXX` code |
| Wrong tone | Adjust Brand voice or pick another variant |
