# Image Data Entry — User Guide

Turn receipt and invoice photos into spreadsheet rows for your business.

## Before you start

1. Get a free activation code at [project-a3.alvinchiew.com](https://project-a3.alvinchiew.com/#signup).
2. Add your **OpenAI API key** in **Settings** and click **Test connection**.

## Install

1. Download **EP08 Image Data Entry** from [Project A3 on GitHub](https://github.com/AlvinChiew/project-a3).
2. Run the installer and open **Image Data Entry**.

## Activate (one time)

1. On the welcome screen, read and tick the **disclaimer**.
2. Enter your business email and `A3-XXXX-XXXX` code, then click **Activate**.

## Create a project

1. Click **New project** on the home screen.
2. **Step 1 — Fields:** add column names (e.g. Vendor, Date, Total) and short descriptions telling the AI where to look on the photo.
3. **Step 2 — Photos:** upload one or more receipt/invoice images.
4. **Step 3 — Review & export:** click **Extract** per row or **Extract all**, edit any cell, then **Export CSV**.

## Copy and delete projects

- **Copy** duplicates the project name (with “(copy)”), fields, extracted values, and photo files.
- **Delete** removes the project and its photos from this device.

## Tips

- Use well-lit, straight-on photos without glare.
- Field descriptions matter — e.g. “Grand total at bottom right”.
- Always review extracted amounts and dates before using the CSV in accounting.

## Common issues

| Problem | What to try |
| ------- | ----------- |
| Extract fails / key error | Re-save your OpenAI key in Settings and Test connection |
| Empty or wrong values | Improve field descriptions; retake a clearer photo |
| Export disabled | Extract or manually enter values for at least one photo |
| App asks to activate again | Use the same business email and a valid `A3-XXXX-XXXX` code |

Photos, extracted values, and settings stay on your device. Your OpenAI key stays in the OS keychain.
